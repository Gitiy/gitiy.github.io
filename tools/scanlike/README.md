# ScanLike · 本地文档扫描效果生成器

在浏览器里把 **PDF / Word / Excel / PowerPoint / 图片** 变成逼真的扫描件。
纯前端、纯本地，**无水印、无体积限制、无页数限制、无次数限制，断网也能用**，文件永不上传。

> **在线地址**：<https://gitiy.github.io/tools/scanlike/> —— 已作为 PWA 部署，可「添加到主屏幕」离线使用。
> 也可以完全离线跑在本机，见下方「怎么用」。

---

## 一、怎么用

**在线用**：直接打开 <https://gitiy.github.io/tools/scanlike/>，或从 <https://gitiy.github.io/tools/> 的工具清单进入。

**本机用**（不联网也能跑）：

1. 双击本目录下的 **`启动.bat`**（Windows）或执行 **`./start.sh`**（macOS / Linux）。
2. 浏览器自动打开 `http://127.0.0.1:8765/`。
3. 把文件拖进左侧队列 → 右边实时预览 → 满意后点右上角 **导出**。

> 关闭那个黑色命令行窗口 = 停止服务。

**不要直接双击 `index.html`。** 浏览器禁止 `file://` 加载本工具需要的 ES 模块与 PDF 渲染线程，
直接打开会看到提示，按提示用启动脚本即可。

没有 Python 也行，任意静态服务器都可以：

```bash
npx --yes serve -l 8765 .
```

**手机上也能用**：手机与本机连同一个 Wi-Fi，把 `启动.bat` 里的地址改成局域网 IP
（`python -m http.server 8765 --bind 0.0.0.0`），手机浏览器访问 `http://<电脑IP>:8765/` 即可。
界面在窄屏下会自动切换成抽屉式布局，触控热区加大。

## 二、功能一览

| 能力 | 说明 |
|---|---|
| **快速转换** | 全本地处理，A4 单页约 0.2 秒；12 页 300DPI 约 5 秒出文件，且**导出时界面不卡** |
| **扫描效果** | 模糊 / 噪点 / 旋转 / 纸张泛黄 / 边缘阴影 / 边框，实时预览，所见即导出 |
| **文档与图片** | PDF、Word、Excel、PowerPoint、PNG/JPG/WebP/BMP/GIF，保留原始排版 |
| **加密 PDF** | 带密码的文档会弹出输入框，密码错误可重试，也可跳过 |
| **签名与印章** | 手写签名板、生成圆形印章、上传签名/印章图片；拖动摆放，大小旋转透明度可调 |
| **自定义水印** | 文字或图片水印，支持平铺整页、任意角度、任意颜色与透明度 |
| **PDF 元数据** | 标题、作者、主题、关键词、创建者、生产者、时间 |
| **页面缩略图** | 长文档（>8 页）自动展开底部缩略图条，点击跳页；短文档默认收起 |
| **自动保存** | 签名、印章、水印与全部参数存在本机，刷新/重开浏览器都还在 |
| **亮暗主题** | 默认跟随系统，也可手动锁定亮色/暗色，选择会被记住 |
| **移动端友好** | 响应式抽屉布局，触控热区加大；选中覆盖层后可直接用手指拖动 |
| **离线可用** | Service Worker 缓存全部资源，首次用过之后断网也能完整转换，可安装到桌面 |

## 三、可调参数

**纸张与姿态**：旋转角度、旋转随机抖动、边缘阴影、扫描边框、边框粗细

**质感与噪点**：噪点强度、模糊、纸张泛黄、亮度、对比度、饱和度

**输出设置**：色彩模式（彩色/灰度/黑白传真/复古）、输出分辨率（72–400 DPI）、
导出格式（PDF / PNG / JPG）、JPG 质量、保持原始页面尺寸、页面范围（`1-3,5,8-`）、随机种子

> 选「黑白（传真）」时会多出一个 **黑白阈值** 滑块：高于该亮度的算白纸，其余压成纯黑。
> 默认 50%，调高会保留更多浅色笔迹（表格线、浅色印章不会被吃掉）。

**PDF 元数据**：标题、作者、主题、关键词、创建者、生产者（标题留空则自动用原文件名）

**预设**：内置八种 ——「**清除所有效果**（一键归零，输出与原件一致）/ 轻度扫描 / 标准扫描件 / 老旧复印件 /
复印机黑白 / 黑白传真 / 重度噪点 / 复古泛黄」，也可以把当前参数存成自己的预设（存在浏览器本地）。

> 「清除所有效果」只清扫描效果，会保留 DPI、导出格式、页面范围与 PDF 元数据；
> 想连输出设置一起还原，用侧栏底部的「恢复默认」。

## 四、签名 / 印章 / 水印怎么用

1. **手写签名**：点「手写签名」，用鼠标或手指在白色画板上签，确定后自动裁掉四周空白并贴到页面上。
2. **生成印章**：点「生成印章」，填「环形文字」（公司名）和「下方文字」（如 合同专用章），
   实时预览红色圆章（环形文字 + 五角星 + 下方横排），确定后贴到页面上。
3. **上传图片**：把已有的透明底签名 PNG 或印章照片传进来。
4. **文字水印**：点右上角「＋ 文字水印」，输入文字，可设字号、颜色、角度、透明度，或勾选「平铺整页」。

**摆放方式**：在右侧「扫描效果」预览图上直接**拖动**移动位置，拖右下角小方块**缩放**。
左侧参数面板可精确调水平/垂直位置、大小、旋转、不透明度，以及应用到「全部页 / 仅当前页 / 自定义页码」。

> 签名与印章是在**扫描效果之前**画上去的，所以它们会带上噪点、模糊与纸张色调，
> 看起来是"扫描进去的"，而不是事后贴上去的。

## 六、技术说明

纯前端，没有后端、没有构建步骤：

| 组件 | 作用 |
|---|---|
| `vendor/pdf.min.mjs` + `pdf.worker.min.mjs` | Mozilla pdf.js，PDF 页 → 位图（含加密文档密码回调） |
| `vendor/pdf-lib.min.js` | 位图 → 新 PDF（含元数据写入） |
| `vendor/cmaps/`、`vendor/standard_fonts/` | 中日韩字体映射，中文 PDF 不缺字 |
| `vendor/docx-preview.min.js` + `vendor/jszip.min.js` | Word 文档渲染（保留分页、表格、图片、页眉页脚） |
| `vendor/xlsx.full.min.js` | Excel 解析与数字格式 |
| `vendor/html-to-image.js` | DOM → Canvas 栅格化（Word / Excel 走这条路） |
| `office.js` | **自研 PPTX 渲染器**（DrawingML：形状、文本框、图片、表格、背景），直接画到 Canvas |
| `effects.js` | 效果管线：Canvas 滤镜 + 覆盖层 + 噪点贴图 + 旋转/边框/阴影 |
| `scan-worker.js` | **效果处理线程**：整条管线跑在 Worker + OffscreenCanvas 上 |
| `sw.js` + `manifest.webmanifest` | 离线缓存与安装到桌面 |

**处理流程**

```
PDF  ─┐
图片 ─┼→ 位图 → 模糊/亮度/对比度/饱和度/色彩模式
Word ─┤         → 画上签名/印章/水印
Excel─┤         → 噪点贴图 + 纸张泛黄（黑白模式在此之后做硬阈值二值化）
PPT  ─┘         → 旋转 + 白纸底 + 投影 + 边缘阴影 + 边框
                → JPEG/PNG → 新 PDF（写入自定义元数据）
```

**界面主题**

配色参照 **shadcn/ui + Radix Colors + Tailwind** 的语义化 token 体系，色板取 Tailwind 的
zinc / blue / green / amber / red 标准阶梯。亮暗两套用 CSS 的 `light-dark()` 表达，
**同一份 token 定义同时给出两种色值**，浏览器按 `color-scheme` 自动选择 —— 不用维护两份色板，
新增一个颜色只需要写一行。

- 默认跟随系统（`color-scheme: light dark`）
- 右上角按钮循环切换：跟随系统 → 亮色 → 暗色，选择存在本机
- 手动指定时只切换 `:root` 的 `color-scheme`，`light-dark()` 会自动跟着换
- 首屏渲染前有内联脚本先定好主题，避免闪一下默认配色
- 连画布上的选中框颜色也会跟着主题走

**性能设计**

- **效果管线跑在 Worker 里**（`scan-worker.js` + OffscreenCanvas），最多 3 个 worker 组成线程池。
  实测 12 页 300 DPI 导出：主线程**最大卡顿仅 41–50 ms**（未 Worker 化时是秒级冻结），
  进度条与「取消」按钮全程可用。
- **多页流水线**：主线程渲染第 N+1 页的同时，worker 在处理第 N 页，两者不再互相等待。
  12 页 300 DPI 导出从 12.7 秒降到 5.2 秒。
- **噪点用贴图合成**，不再逐像素跑 ImageData 循环（原来在 30 MP 页面上是两次 ~120 MB 内存拷贝）。
  噪声贴图用固定种子生成，保证同一页在任何 worker 上都得到完全一致的结果。
- 按像素预算限制同时在内存里的页数，超大页面自动减少并发。
- 单页像素上限 30 MP，超出自动降采样防止浏览器内存溢出。

**已知限制**

- 导出的是**位图 PDF**（内容被拍平，不可再选中文字）——这正是扫描件的本质，与原版行为一致。
- PPT 渲染器覆盖常见元素（文本框、形状、图片、表格、背景、组合），
  但**不支持**动画、SmartArt、图表、艺术字、3D 效果等复杂对象，这类页面会缺失对应元素。
- Excel 分页按行高切分，合并单元格跨页时可能被拆开（与真实表格打印一致）。

**离线缓存与改代码**

`sw.js` 的策略是：`vendor/` 下的第三方库缓存优先（pdf.js 的 worker 有 1MB，走缓存最快），
其余本机文件（html / css / js）**网络优先、断网回落缓存**——所以改完代码**刷新一次**就能看到新版，
同时断网依然完整可用。

万一还是看到旧界面，在开发者工具 → Application → Storage → Clear site data 清一次即可。

## 七、目录结构

```
scanlike/
├─ 启动.bat / start.sh    一键启动
├─ index.html             界面
├─ styles.css             样式（含移动端响应式）
├─ app.js                 界面逻辑、文件管理、覆盖层、缩略图、导出
├─ effects.js             效果管线（可独立复用）
├─ office.js              Office 解析与渲染
├─ scan-worker.js         效果处理线程
├─ sw.js                  离线缓存
├─ manifest.webmanifest   PWA 清单
├─ icon.svg / icon-*.png  图标（PNG 供 iOS 添加到主屏幕）
├─ vendor/                所有第三方库（已本地化，离线可用）
└─ （回归测试套件在开发仓库中，未随线上版本发布）
```

### 与 tools/ 下其他工具共存

`tools/` 目录本身有一个 Tools PWA，注册了作用域为 `/tools/` 的 Service Worker。
本工具是独立子应用，有自己的 SW（作用域 `/tools/scanlike/`），更具体的作用域优先，两者互不干扰。
另外 **Cache Storage 按 origin 共享**，因此两个 SW 在 `activate` 时都只清理各自前缀的缓存
（`scanlike-*` / `Tools*`），不会误删对方的离线缓存。
